# Super Store Sales Dashboard

My first end-to-end Excel project: an interactive dashboard built on 9,994 Superstore transactions to explore sales performance across regions, categories, shipping modes, and time.

## Project Overview
This project analyzes 9,994 Superstore transactions to answer different business questions. With Region and Year slicers, users can filter the dashboard and explore the data interactively.

## What I Built
- 10 Pivot Tables to answer different business questions
- Pivot Charts: Pie, Doughnut, Line, Column, and Bar
- Interactive Slicers for Region and Year
- KPI Cards for Total Sales, Average Sales, Transactions, and Total Quantity
- A clean and easy-to-understand dashboard layout

## Key Insights
- Total Sales: ₹58.2 lakh, with an Average Sales value of 582.37
- Total Quantity Ordered: 25,123 units
- Standard Class accounted for 58% in the Ship Mode Sales chart
- West (32%) and East (29%) recorded the highest shares of regional transactions
- New York City ranked first among the top 5 cities by sales, generating ₹6.54 lakh
- Office Supplies recorded 6,026 transactions in the category-wise analysis
- The Consumer segment led in quantity ordered, with 13,030 units
- Monthly quantity ordered peaked in September (2,858) and November (3,039), followed by December (2,740)

## Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, KPI Cards)

Good data analysis isn't just about creating charts. It's about asking the right questions, identifying meaningful insights, and presenting them clearly.
